# M2.7 — Обратная связь о действиях жителей

## Цель

Сделать поведение семьи понятным игроку: показывать, какое бытовое действие было выполнено последним и кто его инициировал.

## Реализация

- ResidentService сохраняет последнее действие семьи: подпись, источник и игровую минуту.
- Источник различает автономное решение семьи и действие, запущенное игроком.
- Данные входят в существующее сохранение residents; отдельная версия сохранения не требуется.
- Старые сохранения без этих полей отображают нейтральное состояние «Пока действий не было».
- Панель заселённого дома показывает последнее действие и его источник.
- Автономные и ручные действия проходят через общий исполнитель действий и используют прежние cooldown/восстановление потребностей.

## Границы

- Показывается только последнее действие, это не журнал событий.
- Не добавляются новые потребности, расходы, доходы или новые действия.
- Не меняются пороги автономии и расписание.
- Godot Editor/runtime на устройстве не запускался; GitHub Actions не заменяет игровой тест.
