# M3.2 — Интерфейс журнала денежных операций

## Реализовано
- Добавлена кнопка «Журнал операций» в панель управления районом.
- Всплывающее окно показывает текущий баланс и число сохранённых операций.
- Операции выводятся от новых к старым.
- Для каждой записи показываются причина, дата/время и сумма.
- Доходы и расходы визуально различаются цветом и знаком суммы.
- Пустое состояние объясняет, что список заполнится после первых денежных операций.
- История берётся из EconomyService и использует сохранённые записи M3.1; отдельное хранилище не создаётся.

## Ограничения
- Отображаются последние 100 операций, которые хранит EconomyService.
- Этап не меняет стоимость строительства, награды или баланс.
- Окно рассчитано на горизонтальную ориентацию игры.

## Проверки
- GitHub Actions проверяет импорт/запуск Godot и Web Export.
- После публикации нужно проверить открытие окна и читаемость на iPhone.
