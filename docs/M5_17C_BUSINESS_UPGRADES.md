# M5.17c — улучшения привлекательности бизнеса

## Улучшения
- У каждого заведения два уровня улучшения привлекательности.
- Стоимость первого уровня — 35 000 ₽, второго — 75 000 ₽.
- Каждый уровень повышает вес заведения при распределении общего потока покупателей на 25% относительно базового веса.
- Каждый уровень добавляет 500 ₽ ежедневных операционных расходов.
- Улучшения можно приобретать независимо для каждого заведения; тип бизнеса не меняется.

## Влияние на спрос
- Общий поток покупателей района не увеличивается от улучшений.
- Покупатели распределяются пропорционально весам активных заведений.
- Остаток после целочисленного распределения выдаётся по стабильному порядку ID участков.
- Это создаёт конкуренцию за покупателей: улучшенное заведение получает большую долю, но не генерирует дополнительный спрос.

## Сохранения
- Уровень хранится в поле `upgrade_level` внутри существующей записи бизнеса.
- Старые сохранения без этого поля получают уровень 0.
- Некорректные значения ограничиваются диапазоном 0–2.
- Уровень улучшения не сбрасывается при приостановке заведения.
