# M6.3 — Карточка дома и семьи

## Вкладки карточки
- Семья: состав, роли, текущая активность, настроение и удовлетворённость.
- Потребности: энергия, сытость, гигиена, досуг и комфорт дома с полосами прогресса.
- Цели: личные цели жителей, прогресс и состояние выполнения.
- События: активное семейное событие и три последних события из истории семьи.

## Интеграция
- Источник данных — `ResidentService.get_family_at_plot(selected_plot_id)`.
- Карточка видна только для выбранного заселённого дома.
- Смена вкладки повторно читает текущее состояние семьи; сигнал `residents_changed` обновляет панель через существующий обработчик выбора участка.
- Существующие интерактивные действия, автономия, отношения и выбор событий остаются в прежних обработчиках.
- Текстовая сводка заменена компактным сообщением, чтобы не дублировать новую карточку.

## Визуальные ограничения
- Буквенные аватары — временное решение; художественные портреты добавляются отдельным графическим этапом.
- Визуальные полосы показывают фактические проценты, не подменяя игровую симуляцию.

## Проверка
Статически проверяются существующие поля ResidentService, все четыре вкладки, реальные значения потребностей и целей, история событий, вызовы действий и обработчик обновления. Godot runtime, GitHub Actions и Web Export не запускались.
