# M5.16b — индивидуальная покупка участков

## Покупка земли
- Открытие доступа к восточному кварталу по-прежнему стоит 300 000 ₽.
- После открытия каждый из четырёх участков приобретается отдельно за 80 000 ₽.
- Выбор непроданного участка показывает цену и кнопку покупки.
- После успешной оплаты участок получает флаг собственности, сохраняется в мире и становится доступен для строительства.
- Строительство защищено проверкой собственности на уровне мира, а не только интерфейса.

## Интеграция
- В коммунальные службы, их зоны и инфраструктурное обслуживание передаются только принадлежащие игроку участки.
- Генератор районных происшествий выбирает только принадлежащие игроку участки.
- Новые участки становятся доступны для строительства и бизнеса только после покупки.

## Совместимость сохранений
- Шесть стартовых участков считаются собственностью игрока.
- В новых сохранениях открытие восточного квартала не приобретает автоматически все четыре площадки.
- Старые сохранения, где восточный квартал уже был открыт до этой версии и поле собственности отсутствовало, мигрируют с четырьмя уже приобретёнными участками, чтобы не отнимать ранее доступную землю.
