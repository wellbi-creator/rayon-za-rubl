# M2.18 — События важных изменений отношений

## Цель
Дать игроку заметную обратную связь, когда отношения конкретных членов семьи переходят в новую категорию после разговора.

## Что добавлено
- После ручного или автономного персонального разговора проверяются пороги отношений пары.
- При переходе вверх через 70/100 журнал получает событие о хороших отношениях.
- При переходе вверх через 85/100 журнал получает событие об очень хороших отношениях.
- При снижении ниже 45/100 журнал получает событие о напряжённых отношениях.
- Каждая пара и каждый порог фиксируются один раз, чтобы повторные разговоры не засоряли журнал одинаковыми сообщениями.
- События используют существующий семейный журнал и пометки источника «Игрок» / «Автономия».

## Совместимость и границы
- Состояние отметок хранится в данных семьи; старые сохранения получают пустой словарь при загрузке.
- Формат отношений, их скорость изменения, настроение, удовлетворённость и экономика не меняются.
- Пассивные почасовые изменения отношений не создают milestone-событий; учитываются только явные ручные и автономные разговоры.
- Godot Editor/runtime локально не запускался; требуется проверка в Godot.
