# M5.15a — зоны обслуживания коммунальных служб

## Цель
Связать коммунальные бригады с конкретными участками текущей районной карты и учитывать территориальную доступность при устранении происшествий.

## Правила
- Каждый сотрудник службы предоставляет одну бригадную единицу; одна единица может обслуживать один участок.
- При найме сотрудник автоматически получает первый ещё не назначенный этой службе участок, если такой участок есть.
- Игрок может изменить назначения через кнопку «Зоны» в панели коммунальных служб.
- Нельзя назначить больше участков, чем работников службы; нельзя назначить один участок дважды одной службе.
- При увольнении, если назначений стало больше доступного штата, лишние назначения снимаются с конца списка.
- Районное происшествие получает целевой участок при создании и сохраняет его.
- Собственная служба и скидка её эффективности/качества доступны только если целевой участок входит в её назначенную зону. Иначе решение выполняет подрядчик без скидки.
- Разные службы могут обслуживать один и тот же участок; ограничения применяются отдельно по каждому направлению.

## Сохранения
- Список назначенных участков сохраняется в данных коммунальных служб.
- Старые сохранения без этого поля получают начальное назначение по одному участку на каждого имеющегося сотрудника, в пределах шести текущих участков.
- Старые активные события без целевого участка получают участок 0; новые события сохраняют фактически выбранный целевой участок.

## Границы этапа
Покупка коммунальной техники, её характеристики и влияние качества обслуживания на удовлетворённость жителей/состояние инфраструктуры остаются в M5.15b.
