# M5.14 — автоматическое обслуживание и качество коммунальных служб

## Цель
Добавить управляемую ежедневную профилактику и связать качество работы персонала с эффективностью устранения районных проблем.

## Правила
- Автообслуживание включается отдельно для каждого направления и доступно при наличии хотя бы одного сотрудника.
- Один раз за игровые сутки активная служба проверяет необходимость профилактической работы.
- При качестве ниже 100% служба пытается выполнить одну плановую работу.
- Стоимость работы: 150 ₽ базово + 100 ₽ за каждого сотрудника направления.
- При успешной оплате качество повышается на 3 + округлённую эффективность штата / 20 процентных пунктов, максимум до 100%.
- Если средств недостаточно, работа не засчитывается, качество снижается на 3 пункта.
- Если штат есть, но автообслуживание выключено, качество снижается на 2 пункта за игровые сутки.
- При качестве 100% и включённом автообслуживании лишние расходы не начисляются.
- Без сотрудников обслуживание не выполняется, качество не изнашивается.
- Скидка на решение районного события теперь учитывает и эффективность штата, и качество: при 100% качества прежний баланс M5.12 полностью сохраняется.

## Интерфейс
Панель коммунальных служб показывает качество каждого направления, среднее качество района и количество служб с включённым автообслуживанием. Для каждого направления есть переключатель «Авто ВКЛ/ВЫКЛ» и отображается стоимость одной плановой работы.

## Сохранения
Новые поля качества, режима обслуживания и последнего обработанного дня сохраняются. При загрузке старого сохранения качество по умолчанию равно 100%, автообслуживание выключено, повторные/задним числом начисления не выполняются.

## Границы этапа
Назначение территориальных зон, распределение нескольких бригад по участкам, покупка коммунальной техники и прямое влияние качества на удовлетворённость жителей относятся к следующим этапам.
