# M1.9 — Подготовка дома к заселению

## Цель
Отделить завершение строительных работ от фактической готовности дома принять семью.

## Реализация
Добавлен MoveInService с сохраняемым чек-листом для каждого построенного участка:
1. Электричество.
2. Водоснабжение.
3. Отопление.
4. Сантехника.
5. Внутренняя отделка.
6. Мебель.
7. Освещение.
8. Благоустройство территории.

В контекстной панели построенного участка можно выбрать этап и отметить его выполненным. Интерфейс показывает количество завершённых проверок из восьми. После выполнения всех пунктов дом получает статус «Готов к заселению».

## Сохранения
- Чек-листы сохраняются отдельно в блоке `move_in`.
- Старые сохранения без этого блока продолжают загружаться: для них создаётся пустой чек-лист.
- Прогресс не сбрасывается при перезапуске игры.

## Ограничения прототипа
- Отметки этапов пока ручные и не списывают деньги.
- Цены материалов, услуг и мебели намеренно не придуманы: их нужно отдельно сбалансировать через EconomyService.
- Статус готовности уже определяется, но система семей/фактического заселения ещё не реализована. Это следующий этап после появления жителей.
- Никакие платежи не обходят EconomyService; на этом этапе новых транзакций нет.

## Проверки
- Godot Editor/runtime локально не запускался.
- GitHub Actions выполняет headless-проверку после открытия PR.
- Визуальная проверка на реальном телефоне или ПК не проводилась.
