# M3.1 — Основа журнала денежных операций

## Реализовано
- EconomyService записывает каждое успешное списание и начисление.
- Запись содержит сумму со знаком, причину операции, баланс после операции и Unix-время.
- История ограничена последними 100 операциями, чтобы сохранение не разрасталось бесконечно.
- История включается в обычное сохранение игры и восстанавливается при загрузке.
- Старые сохранения без поля economy_transactions продолжают загружаться с пустой историей.
- Неуспешные списания и установка баланса при загрузке не создают фиктивных операций.

## Границы этапа
- Этот этап добавляет слой данных и сохранение истории.
- Отдельный экран/панель просмотра истории будет реализован следующим этапом M3.2.
- Существующие суммы, стоимость строительства, награды и правила экономики не меняются.

## Проверки
- GitHub Actions проверяет импорт проекта, запуск главной сцены и Web Export.
- После публикации требуется проверить на iPhone, что текущая игра запускается и сохранённый прогресс не сбрасывается.
