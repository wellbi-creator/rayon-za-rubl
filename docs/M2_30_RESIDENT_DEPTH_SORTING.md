# M2.30 — Сортировка жителей по глубине изометрической сцены

## Цель
Сделать пересечения и расположение нескольких жителей визуально аккуратнее в изометрической перспективе, не меняя симуляцию жителей.

## Реализовано
- Отрисовка жителей теперь собирает временные записи персонажей перед выводом на экран.
- Персонажи сортируются по координате точки контакта с землёй (позиции ног): сначала дальние, затем ближние.
- Для одинаковой глубины используются координата X, ID участка и индекс члена семьи — это даёт стабильный порядок при каждом кадре.
- Порядок групп в массиве ResidentService больше не влияет на то, какой персонаж визуально окажется поверх другого.
- Существующие маршруты, фазы ходьбы, idle-анимация и фильтрация активностей сохранены.

## Совместимость и ограничения
- Изменения касаются только временного списка отрисовки внутри DistrictWorld.
- Не меняются расписания, ResidentService, ID участков, сетка, экономика, строительство, сохранения и формат данных.
- Сортировка применяется к жителям относительно других жителей. Полная межслойная окклюзия жителей со зданиями, деревьями и транспортом требует отдельного этапа общей сортировки объектов сцены.

## Проверка
GitHub Actions выполняет автоматическую проверку проекта на PR и после слияния. Godot Editor/runtime локально не запускался; визуальное поведение и отсутствие мерцания при пересечении персонажей нужно дополнительно проверить в запущенной игре на ПК и телефоне.
