# M2.24 — Изометрический прототип стартового района

## Цель
Создать отдельную запускаемую сцену-прототип, на которой проверяется читаемость ромбической карты, дорог, участков, домов и окружения до переноса всей действующей игры.

## Содержимое прототипа
- Ромбическая карта 9×7 на общей сетке IsometricGrid.
- Две пересекающиеся улицы, выложенные из изометрических ячеек.
- Шесть стартовых участков, включая дом Бабы Зины.
- Объёмный дом с двумя видимыми фасадами и двумя плоскостями крыши.
- Деревья, кусты и фонари с мягким свечением.
- Выбор ячейки мышью и касанием, перемещение камеры и масштабирование.

## Запуск
Открыть в Godot сцену `res://scenes/isometric_district_preview.tscn`. Основная сцена игры пока остаётся прежней: прототип изолирован, чтобы не повредить сохранения, ID участков, строительство и симуляцию жителей во время проверки визуального направления.

## Ограничения
- Это первый художественно-технический блок-аут, а не финальный арт.
- Не подключены реальные участки/состояния из DistrictWorld и данные жителей.
- Нет полноценной дорожной сети, маршрутов транспорта, зданий всех типов и UI.
- Не меняются основной игровой цикл, экономика, GameTime и формат сохранений.
- Godot Editor/runtime не запускался в среде разработки; PR проверяется GitHub Actions.
