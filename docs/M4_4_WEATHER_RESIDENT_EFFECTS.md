# M4.4 — влияние погоды на жителей

## Реализация

- ResidentService получает текущие сезон и погоду через `set_environment`; источником состояния остаётся WeatherService.
- Во время прогулок дождь, снег и туман ускоряют снижение потребности в досуге.
- Ясная погода весной и летом немного смягчает снижение досуга на прогулке.
- Зимой прогулки требуют немного больше энергии.
- Изменения проходят через существующие потребности, поэтому влияют на настроение и удовлетворённость уже работающей модели жителей.
- Для жителей дома и спящих погодные модификаторы прогулки не применяются.
- Новые поля сохранения не добавляются: сезон и погода восстанавливаются из WeatherService, а потребности жителей продолжают сохраняться штатно.

## Стартовые модификаторы

| Условие | Изменение за игровую минуту |
|---|---:|
| Прогулка под дождём | +0,025 к расходу досуга |
| Прогулка в снег | +0,035 к расходу досуга |
| Прогулка в туман | +0,015 к расходу досуга |
| Ясно весной/летом | −0,010 к расходу досуга |
| Прогулка зимой | +0,012 к расходу энергии |

Значения являются мягкими стартовыми коэффициентами и требуют балансировки по результатам игры.

## Проверки

Ожидаются GitHub Actions: импорт проекта, headless-запуск и Web Export. Визуальное подтверждение и игровой баланс требуют последующей проверки на iPhone.
