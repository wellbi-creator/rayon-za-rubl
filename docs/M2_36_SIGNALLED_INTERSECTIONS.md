# M2.36 — регулируемый перекрёсток

## Цель
Убрать визуальное пересечение автомобилей друг сквозь друга на демонстрационном крестообразном перекрёстке. Управление остаётся частью визуальной демонстрации транспорта и не меняет экономику, жителей, расписания, дороги или сохранения.

## Реализация
- Два направления движения объединены в фазы: горизонтальная и вертикальная.
- Фазы переключаются автоматически через равные интервалы.
- Машина, приближающаяся к перекрёстку на красный сигнал, плавно снижает скорость и останавливается перед условной стоп-линией.
- Машины, уже въехавшие в зону перекрёстка, завершают проезд даже при переключении сигнала.
- После включения зелёного сигнала ожидающие машины плавно трогаются.
- Встречные потоки одного направления продолжают использовать отдельные полосы.
- Светофоры отображаются в изометрической сцене и показывают состояние соответствующего направления.
- Существующая система появления/исчезновения машин и общая сортировка глубины сохраняются.

## Ограничения текущего этапа
Это первая демонстрационная реализация для одного крестообразного перекрёстка и четырёх тестовых автомобилей. Она не является полноценной дорожной симуляцией и пока не регулирует пользовательские транспортные объекты из внешней системы.

## Проверка
- Автоматические проверки импорта проекта и Web export выполняются GitHub Actions для pull request.
- После публикации необходимо визуально проверить остановку на красный, проезд на зелёный, отсутствие наложения потоков и читаемость сигналов при разных масштабах камеры.
