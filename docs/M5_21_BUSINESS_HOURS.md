# M5.21 — Гибкие графики коммерческих заведений

## Режимы
| Режим | Часы | Вес спроса | Операционные расходы |
|---|---|---:|---:|
| Обычный | 08:00–20:00 | 100% | 100% |
| Продлённый | 06:00–22:00 | 115% | 125% |
| Круглосуточный | 00:00–24:00 | 130% | 150% |

## Правила
- График хранится отдельно для каждого участка.
- Изменить режим может владелец только собственного, не сданного в аренду заведения.
- Арендованное помещение продолжает работать по сохранённому графику; график доступен для просмотра.
- Режим влияет на вес в распределении общего суточного спроса, но не увеличивает общий поток покупателей.
- Операционные расходы масштабируются по фиксированному проценту режима, включая надбавки за улучшения.
- Визуальная вывеска использует часы конкретного заведения; пауза заведения имеет приоритет и всегда закрывает вывеску.
- Старые сохранения получают режим standard.

## Проверки логики
- При одинаковых прочих параметрах обычный режим остаётся без изменений относительно прежнего баланса.
- Продлённый и круглосуточный режимы увеличивают долю спроса и расходы только выбранного бизнеса.
- Сумма распределённых покупателей равна исходному общему спросу.
- Арендаторский график нельзя менять через UI владельца.
- Старые сохранения корректно получают стандартный режим.

## Ограничения
Статические проверки не заменяют запуск Godot и визуальную проверку на устройстве.
