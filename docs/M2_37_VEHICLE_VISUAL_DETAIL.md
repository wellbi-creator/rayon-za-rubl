# M2.37 — Визуальная детализация автомобилей

## Цель
Сделать уже работающие демонстрационные автомобили более читаемыми на изометрической карте, не затрагивая проверенную механику движения.

## Реализовано в этом этапе
- Силуэт автомобиля дополнен четырьмя тёмными колёсами.
- Передняя и задняя части кабины получили отдельные стеклянные панели.
- Добавлены небольшие передние и задние световые элементы.
- Все детали рассчитываются относительно текущего угла автомобиля, поэтому корректно поворачиваются вместе с машиной на горизонтальных и вертикальных участках.
- Прозрачность автомобиля у краёв маршрута сохраняется для всего силуэта и его деталей.

## Границы
- Не меняются дорожный граф, маршруты, скорость, полосы, таймеры появления и исчезновения.
- Не меняются камера, участки, жители, экономика, сохранения и игровые данные.
- Это визуальное улучшение демонстрационного транспорта, не полноценная симуляция автомобилей.

## Проверка
GitHub Actions проверяет импорт проекта и Web export. После публикации требуется визуальная проверка на iPhone: детали машин должны быть заметны, не мерцать и не менять направление независимо от корпуса.
