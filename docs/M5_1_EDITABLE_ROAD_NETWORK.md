# M5.1 — редактируемый граф дорожной сети

## Что добавлено

- Дорожная сеть теперь поддерживает добавление клеток в пределах карты.
- Новая клетка должна примыкать по стороне хотя бы к одной существующей дороге; изолированные сегменты отклоняются.
- Удаление клетки допускается только тогда, когда оставшаяся сеть сохраняет связность. Это защищает маршруты от случайного разрыва.
- Добавлены сериализация и восстановление размера карты и набора дорожных клеток.
- Загрузка проверяет формат, границы и связность; при некорректных данных прежняя сеть остаётся нетронутой.
- BFS-маршрутизация и выдача world-space точек продолжают использовать тот же единый набор дорожных клеток.

## Совместимость и границы этапа

- Исходная крестообразная сеть 9×7 остаётся начальной конфигурацией.
- Визуальная отрисовка дорог и движение четырёх демонстрационных машин не меняются.
- Этот этап добавляет безопасный API графа и формат сохранения; пользовательский инструмент рисования дорог, стоимость прокладки и подключение к общему SaveService будут отдельным следующим этапом M5.2.
- Экономика, участки, жители, строительство и существующие сохранения не изменяются.

## Проверки

Ожидаются GitHub Actions: импорт Godot-проекта, headless launch и Web Export. После слияния отдельно проверяется публикация GitHub Pages на merge commit.
