# M5.2 — инструмент прокладки дорог

## Что добавлено

- Кнопка «ДОРОГИ» включает и выключает отдельный режим строительства, не меняя обычный выбор участков.
- При наведении на клетку показывается визуальный предпросмотр: зелёный для допустимой клетки, красный для недопустимой.
- На телефоне и ПК строительство выполняется касанием/кликом по клетке.
- Новая клетка должна находиться в пределах карты, примыкать к существующей дорожной сети по стороне и не занимать участок, дерево или парковую зону.
- Стоимость одного нового сегмента — 5 000 ₽. Списание проходит через EconomyService и отражается в журнале операций.
- После успешной прокладки начисляется 5 XP району.
- Дорожная сеть включена в данные мира и автоматически сохраняется/восстанавливается через существующий SaveService.
- Старые сохранения без поля road_network продолжают загружаться с исходной крестообразной сетью.

## Ограничения этапа

- На этом этапе доступно расширение сети; удаление дорог через интерфейс пока не добавлено.
- Перенастройка полос и маршрутов демонстрационных машин, строительство тротуаров и разные покрытия — будущие задачи.
- Проверка успешного экспорта и публикации выполняется GitHub Actions после открытия PR и слияния.

## Проверки

Ожидаются Godot import/headless launch и Web export. Визуальный результат на iPhone требует отдельного подтверждения в опубликованной игре.
