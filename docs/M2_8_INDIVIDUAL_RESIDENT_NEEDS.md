# M2.8 — Индивидуальные потребности жителей

## Цель
Перейти от одного набора потребностей на семью к отдельным данным каждого члена семьи, сохранив совместимость интерфейса и сохранений.

## Реализация
- Для стартовой семьи созданы три профиля: два взрослых и ребёнок.
- У каждого профиля собственные потребности, настроение, удовлетворённость и коэффициенты изменения потребностей.
- Потребности симулируются отдельно для каждого жителя по игровым минутам.
- Семейные показатели в существующем UI остаются агрегатами — средними значениями индивидуальных данных.
- Действия семьи изменяют соответствующую потребность у каждого члена семьи.
- Индивидуальные данные сохраняются в блоке residents.
- Старые сохранения мигрируют автоматически: текущие семейные потребности копируются в новые индивидуальные профили; семейные показатели пересчитываются как средние.
- Профиль дома предоставляет массив индивидуальных данных жителей для следующих UI-этапов.

## Границы
- Имена и роли стартовой семьи пока условные.
- Автономные и ручные действия пока остаются семейными, не индивидуальными.
- Индивидуальные предпочтения, личные расписания, диалоги и отношения между членами семьи не реализованы.
- Новые расходы и доходы не добавлены.
- Godot Editor/runtime на устройстве не запускался; GitHub Actions не заменяет игровой тест.
