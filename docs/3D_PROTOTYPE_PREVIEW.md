# Первый 3D-прототип района

Это отдельная тестовая сцена, не подключённая к основной игре.

## Что включено
- площадка района и отдельный участок;
- простая дорога и тротуары;
- тестовый дом из базовых 3D-мешей;
- деревья, направленный свет и изометрическая ортографическая камера;
- управление камерой: перетаскивание мышью/пальцем, колесо мыши и жест масштабирования.

## Как открыть
После объединения PR GitHub Actions опубликует отдельную Web-сборку в каталоге `prototype/`. Основная игра останется по прежнему адресу, тестовый прототип будет доступен по адресу:

`https://wellbi-creator.github.io/rayon-za-rubl/prototype/`

## Важно
Это блок-аут для проверки камеры, масштаба и читаемости 3D на целевых экранах, а не финальная графика. Сцена не заменяет основную сцену `scenes/main.tscn`, не меняет игровые сервисы и не затрагивает сохранения.
