# M2.5 — Интерактивные действия жителей

## Цель
Добавить первые управляемые действия, которые помогают семье поддерживать потребности, а не только наблюдать за их снижением.

## Действия
В контекстной панели заселённого дома доступны:
- **Приготовить еду** — восстанавливает сытость.
- **Принять душ** — восстанавливает гигиену.
- **Отдохнуть** — восстанавливает энергию.
- **Досуг** — восстанавливает досуг.

## Распорядок и ограничения
- Приём пищи и душ доступны, когда семья находится дома.
- Отдых доступен дома и во время сна.
- Досуг доступен дома и во время прогулки.
- У каждого действия отдельный cooldown, измеряемый игровыми минутами.
- Cooldown сохраняется вместе с состоянием семьи, поэтому перезапуск игры не сбрасывает ограничение.
- После успешного действия обновляются потребности, настроение/удовлетворённость и панель дома.

## Баланс и сохранения
- Восстановление потребностей и cooldown пока имеют временные прототипные значения.
- Действия не требуют денег и не создают расходов/доходов: цены на питание, коммунальные ресурсы и услуги ещё не утверждены.
- Состояние cooldown хранится в существующем блоке `residents`; отдельная миграция не нужна, старые сохранения продолжают работать.

## Границы этапа
- Потребности и действия общие для семьи, а не для отдельных жителей.
- Нет инвентаря продуктов, рецептов, бытовых предметов, магазинов, кафе, анимаций использования объектов и автономного выбора действий NPC.
- Игрок пока управляет действиями напрямую через выбранный дом.
- Godot Editor/runtime локально не запускался; GitHub Actions не заменяет визуальный тест на устройстве.

## Проверки
GitHub Actions запускается автоматически для PR и после объединения в main.
