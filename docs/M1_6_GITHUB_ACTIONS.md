# M1.6 — GitHub Actions: проверка проекта Godot

## Что делает workflow

Файл `.github/workflows/godot-validation.yml` запускает автоматическую проверку:

- при каждом Pull Request;
- при push в `main`;
- вручную через вкладку Actions.

Используется окружение `barichello/godot-ci:4.3`, соответствующее версии Godot, указанной в `project.godot`.

## Этапы проверки

1. Получение исходников репозитория.
2. Вывод версии Godot в лог.
3. Headless-импорт проекта через редактор Godot — помогает обнаруживать ошибки загрузки ресурсов и парсинга.
4. Запуск основной сцены `res://scenes/main.tscn` без графического окна на ограниченное время.
5. Загрузка логов как артефакта GitHub Actions, даже если предыдущая проверка завершилась ошибкой.

## Что эта проверка подтверждает

Успешный workflow означает, что проект импортируется и основная сцена запускается в headless-окружении Godot 4.3.

## Чего workflow пока не проверяет

- реальный рендеринг и внешний вид карты;
- управление мышью и сенсорным экраном;
- FPS и производительность на телефонах;
- экспорт APK или iOS-приложения;
- полноценные игровые сценарии и баланс.

Headless-запуск — автоматическая техническая проверка, а не замена тестированию на устройстве. Следующим этапом можно добавить тесты игровых сервисов и отдельную сборку Android.
