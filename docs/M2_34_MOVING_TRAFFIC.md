# M2.34 — Первые движущиеся автомобили

## Цель
Показать первые автомобили, которые непрерывно и плавно движутся по уже существующей дорожной сети стартового изометрического района.

## Реализовано
- Два демонстрационных автомобиля получают маршруты из существующего RoadPathNetwork: один по горизонтальной, второй по вертикальной части крестообразной дороги.
- Положение рассчитывается по длине сегмента, а не скачками между клетками.
- При прохождении узлов автомобиль плавно меняет направление и разворачивается на конце маршрута, продолжая движение обратно.
- Угол визуального силуэта следует направлению текущего сегмента.
- Автомобили включены в общую очередь сортировки глубины по точке контакта с землёй.
- Движение обновляется в игровом кадре и не зависит от скорости анимации камеры.

## Границы этапа
- Это визуальная демонстрация движения, а не полноценная транспортная симуляция.
- Не добавляются пробки, столкновения, светофоры, парковка, правила приоритета или влияние трафика на экономику.
- Не меняются дорожная сеть, участки, жители, расписания, баланс и формат сохранений.
- Демонстрационные автомобили не записываются в сохранение и не изменяют состояние игрового мира.

## Проверка
GitHub Actions проверит импорт проекта и запуск главной сцены. После публикации Web-сборки требуется визуально проверить движение машин, повороты и глубину на iPhone и ПК.
