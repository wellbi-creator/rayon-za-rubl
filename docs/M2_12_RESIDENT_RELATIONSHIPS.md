# M2.12 — Отношения между жителями

## Реализовано
- Для каждой пары членов семьи хранится отдельная оценка отношений от 0 до 100.
- Новые семьи начинают с нейтрального значения 60.
- Раз в игровой час отношения немного растут, если оба жителя находятся в одинаковой спокойной активности (дома или на прогулке), имеют хорошее настроение и достаточный комфорт дома.
- Отношения немного снижаются, если у одного из участников очень низкое настроение.
- Среднее отношение жителя к остальным членам семьи отображается в его карточке качественной подписью и числом.
- Хорошие отношения дают небольшой почасовой бонус к удовлетворённости; очень низкие — небольшой штраф.
- Данные хранятся в блоке семьи `relationships`; старые сохранения получают нейтральные значения для отсутствующих пар.

## Границы
- Это первая базовая симуляция отношений внутри семьи, а не полноценная социальная модель.
- Пока нет дружбы/конфликтов с соседями, диалогов, событий отношений, личных границ и ручных социальных действий.
- Значения и скорость изменений — предварительные параметры прототипа.
- Новые доходы и расходы не добавлены.
- Godot Editor/runtime локально не запускался; GitHub Actions проверяет проектные workflow, но не заменяет запуск сцены в Godot.
