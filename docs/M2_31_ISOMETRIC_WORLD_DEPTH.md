# M2.31 — Единая сортировка глубины изометрического мира

## Цель
Согласовать порядок отрисовки основных высоких объектов стартового района и жителей, чтобы персонажи могли естественно уходить за деревья и здания и выходить перед ними в зависимости от положения на земле.

## Реализовано
- Добавлена общая очередь отрисовки для деревьев, участков с их содержимым и жителей.
- Элементы сортируются по глубине на основе координаты Y точки опоры на землю.
- Для совпадающей глубины используется стабильная дополнительная сортировка по X и типу объекта.
- Прежняя сортировка жителей сохранена как часть формирования общего списка.
- Дороги, земля и фоновые элементы окружения остаются нижними слоями; птицы остаются отдельным верхним воздушным слоем.

## Совместимость и ограничения
- Используются только временные записи отрисовки; игровые данные не меняются.
- Не меняются ResidentService, расписания, маршруты, ID участков, сетка, экономика, строительство и сохранения.
- Сортировка деревьев/участков/жителей по опорной точке — практическое приближение для текущей карты. Для сложных крупных спрайтов, навесов и объектов с несколькими независимыми частями может потребоваться разбиение на отдельные слои/сегменты.
- Фонари и небольшая парковая зелень остаются в базовом слое окружения, чтобы не усложнять текущую систему.

## Проверка
GitHub Actions выполнит автоматическую проверку PR. Godot Editor/runtime локально не запускался; требуется отдельная визуальная проверка персонажей, проходящих за деревьями и фасадами, на ПК и телефонах.
