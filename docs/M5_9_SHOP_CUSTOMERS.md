# M5.9 — Первые покупатели магазина

- Каждый работающий магазин создаёт небольшой поток из двух визуальных посетителей.
- Покупатели используют уже существующие пешеходные маршруты района и общий анимированный рендер жителей.
- Движение синхронизировано с визуальным временем мира и не меняет игровую экономику.
- Приостановленный магазин не создаёт посетителей.
- Посетители учитываются в общей сортировке по глубине, поэтому корректно перекрываются домами, деревьями, жителями и транспортом.
- Состояние магазина берётся из BusinessService через уже существующий business_plots; новые данные сохранения не требуются.

Это первый визуальный шаг к полноценной посещаемости. В следующих этапах покупатели смогут влиять на спрос, выручку, качество сервиса и потребность в персонале.
