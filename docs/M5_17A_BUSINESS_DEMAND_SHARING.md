# M5.17a — распределение спроса между магазинами

## Правило общего спроса
- Спрос рассчитывается один раз на весь район по существующим факторам: население, средняя удовлетворённость, репутация и погода.
- Общий поток покупателей распределяется поровну между всеми активными магазинами.
- Если покупателей нельзя разделить поровну, остаток по одному покупателю распределяется магазинам в порядке ID участка.
- Покупатели и выручка каждого магазина записываются в его существующие поля `last_daily_customers` и `last_daily_revenue`.
- Суммарная выручка за день равна общему числу покупателей района, умноженному на средний чек.

## Экономика
- Каждый активный магазин по-прежнему оплачивает собственные операционные расходы.
- Приостановленные магазины не получают покупателей и не создают новые ежедневные операционные расходы.
- Офлайн-периоды обрабатываются существующим `elapsed_days`: дневная выручка и расходы умножаются на число прошедших игровых суток.
- Открытие нового магазина не создаёт дополнительный спрос само по себе, а делит существующий поток с другими магазинами.

## Совместимость
- Новые поля сохранения не добавляются.
- Существующие значения покупателей и выручки продолжают загружаться без миграции.
- Распределение детерминировано сортировкой ID участков, поэтому одинаковое состояние района даёт одинаковый результат.
