# M2.17 — Панель отношений между членами семьи

## Цель
Сделать последствия персональных разговоров прозрачными: игрок должен видеть состояние конкретной пары, а не только усреднённые отношения каждого жителя со всеми родственниками.

## Что добавлено
- Для каждой направленной пары «инициатор → собеседник» панель показывает фактическую оценку отношений от 0 до 100 и текстовую категорию.
- Отображается оставшееся время индивидуальной паузы между выбранными участниками.
- Кнопка разговора автоматически отключается, если пауза ещё действует или один из участников находится вне дома и прогулки.
- Добавлен единый метод получения состояния пары для UI; расчёт использует существующие сохранённые отношения и cooldown без дублирования игровой логики.
- Обновлён GDD.

## Совместимость и границы
- Формат сохранений не меняется: используются существующие данные отношений и cooldown M2.16.
- Общие и автономные разговоры не изменяются.
- Это интерфейс прозрачности, он не меняет баланс отношений, настроение, удовлетворённость или экономику.
- Godot Editor/runtime локально не запускался; требуется последующая проверка в самом проекте.
