# M2.6 — Автономное поведение жителей

## Цель
Сделать семью активным участником симуляции: при включённой автономии она самостоятельно реагирует на базовые потребности, не ожидая нажатий игрока.

## Автоматические действия
- Дома семья может приготовить еду, принять душ, отдохнуть или заняться досугом.
- Во время прогулки семья может восстановить досуг.
- Действие выбирается по порогам потребностей и текущему расписанию.
- Для действий используются те же прототипные значения восстановления и cooldown, что и для ручных команд M2.5.
- Сон по расписанию по-прежнему восстанавливает энергию естественным образом.

## Управление игрока
- Автономия включена по умолчанию для новых семей.
- В панели заселённого дома есть переключатель автономии.
- Настройка хранится отдельно для каждой семьи и сохраняется при перезапуске.
- При выключенной автономии семья не запускает автоматические действия; игрок может использовать ручные команды M2.5.

## Сохранения и баланс
- Настройка автономии хранится в существующем блоке `residents`.
- Для старых сохранений значение по умолчанию — включено.
- Не добавлены расходы, цены, магазины или доходы. Действия остаются бесплатными до согласования экономического баланса.
- Пороги автоматического выбора — начальные прототипные параметры, не финальный баланс.

## Границы этапа
- Решения принимаются на уровне семьи, не отдельного жителя.
- Нет индивидуальных потребностей, маршрутизации к предметам мебели, анимаций бытовых действий, покупки продуктов или посещения бизнеса.
- Работа пока остаётся условным отсутствием на карте; автоматические действия на рабочем месте не моделируются.
- Godot Editor/runtime локально не запускался; GitHub Actions не заменяет визуальную проверку игры на устройстве.

## Проверки
GitHub Actions запускается автоматически для PR и после объединения в main.
