# M1.4 — локальные сохранения и восстановление прогресса

## Что сохраняется

- Баланс района.
- Флаг открытия блокнота Бабы Зины.
- Флаг выполненного ремонта электропроводки.
- Состояние всех участков: свободен, строится, построен или сюжетный дом.
- Прогресс текущего строительства и ID участка.
- Время последнего сохранения для расчёта офлайн-прогресса стройки.

## Поведение

- Сохранение в JSON-файл `user://rayon_save.json`.
- Версия формата сохранения хранится в корневом объекте; неизвестные версии не загружаются.
- Автосохранение выполняется каждые 5 секунд, после важных действий и при закрытии окна.
- При загрузке восстанавливаются баланс, сюжетные флаги и участки.
- Для незавершённой стройки учитывается время с момента последнего сохранения; если срок истёк, дом отмечается построенным.

## Ограничения

- Сохранение локальное для устройства и установки игры; облачная синхронизация не реализована.
- Миграции между версиями пока не реализованы: при изменении схемы потребуется добавить мигратор.
- Состояние камеры, выбранный участок и настройки интерфейса не сохраняются.
- Godot не запускался. Чтение/запись user://, корректность JSON и офлайн-прогресс требуют проверки в Godot на целевых платформах.
