# M2.9 — Индивидуальная автономия жителей

## Цель

Перевести автономное бытовое поведение с уровня семьи на уровень отдельного жителя.

## Реализация

- Каждый житель независимо оценивает собственные показатели сытости, гигиены, энергии и досуга.
- Доступные действия выбираются по текущей активности семьи и личным потребностям конкретного жителя.
- Действие восстанавливает потребность только того жителя, который его выбрал.
- Cooldown каждого действия хранится отдельно у каждого жителя.
- Общий переключатель автономии семьи остаётся главным выключателем; дополнительно у каждого жителя есть собственный переключатель.
- Последнее автономное действие записывается в профиль жителя и отображается в панели дома.
- Состояние индивидуальной автономии, cooldown и последнее действие сохраняются.
- Старые сохранения получают значения по умолчанию при загрузке.
- Частота пересчёта настроения и удовлетворённости остаётся один раз в игровой час.

## Границы

- Расписание пока общее для семьи; индивидуальные действия используют текущую активность семьи.
- Действия не перемещают персонажей к объектам и не запускают отдельные анимации.
- Семейные ручные действия из существующей панели по-прежнему применяются ко всем членам семьи.
- Не добавлены новые расходы/доходы.
- Godot Editor/runtime на устройстве не запускался; GitHub Actions не заменяет игровой тест.
