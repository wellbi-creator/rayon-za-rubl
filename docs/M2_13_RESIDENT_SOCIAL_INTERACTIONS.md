# M2.13 — Социальные взаимодействия жителей

## Реализовано
- В панели заселённого дома добавлена кнопка разговора для каждого жителя.
- Разговор доступен, когда инициатор и хотя бы один другой член семьи находятся дома или на прогулке.
- Успешный разговор повышает отношения инициатора с доступными членами семьи на 5 пунктов (до 100), а настроение и удовлетворённость участников — на 1 пункт.
- Для каждого инициатора действует отдельная пауза в 120 игровых минут.
- Время следующего доступного разговора хранится в индивидуальном состоянии жителя и сохраняется.
- Старые сохранения получают значение по умолчанию без сброса существующих отношений.
- GDD обновлён.

## Границы
- Это простое действие игрока, а не система диалогов с ветвлением.
- Разговор не создаёт новых расходов или доходов.
- Не добавлены новые анимации, реплики, характеры или социальные события.
- Godot Editor/runtime локально не запускался; GitHub Actions не заменяет проверку сцены в Godot.
