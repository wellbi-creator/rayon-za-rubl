# M2.10 — Индивидуальные распорядки жителей

## Цель
Разделить ежедневную активность членов семьи, чтобы индивидуальная автономия учитывала личное расписание, а не только общий график семьи.

## Расписания
- Взрослые пока используют утверждённый базовый график семьи: сон 00:00–06:00 и 22:00–00:00, домашнее время 06:00–08:00 и 20:00–22:00, работа 08:00–17:00, прогулка 17:00–20:00.
- Ребёнок: сон 00:00–07:00 и 22:00–00:00; сборы дома 07:00–08:00; занятия вне карты 08:00–14:00; дома 14:00–17:00; прогулка 17:00–20:00; отдых дома 20:00–22:00.
- Расписания data-driven и привязаны к стабильному ID жителя.

## Симуляция
- Активность каждого жителя обновляется независимо.
- Энергия восстанавливается только во время личного сна.
- Автономные действия выбираются по личной активности и собственным потребностям.
- Во время занятий ребёнок не выполняет бытовые действия дома.
- Семейная активность сохраняется как агрегированное представление для существующей карты и совместных действий.
- Панель заселённого дома показывает текущее занятие каждого жителя.

## Совместимость и границы
- Новые поля активности восстанавливаются из расписания для старых сохранений.
- Не добавлены школы, рабочие места, транспорт, pathfinding, индивидуальные анимации или новые расходы/доходы.
- Взрослые пока имеют одинаковый базовый распорядок.
- Godot Editor/runtime локально не запускался; требуется проверка в реальном игровом запуске позднее.
