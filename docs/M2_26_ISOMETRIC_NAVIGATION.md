# M2.26 — Изометрическая навигация и управление камерой

## Цель
Сделать перемещение по основной изометрической карте удобным на ПК и сенсорных устройствах.

## Реализовано
- Плавное следование камеры за целевой позицией.
- Ограничение перемещения видимыми границами стартового района с небольшим визуальным запасом.
- Приближение и отдаление с колёсика мыши относительно позиции курсора.
- Pinch-to-zoom через системное событие magnify на поддерживаемых сенсорных устройствах.
- Перетаскивание карты правой/средней кнопкой мыши и одним пальцем.
- Поддержка панорамирования через gesture-событие.
- Перемещение камеры клавишами WASD и стрелками.
- Существующий выбор участков мышью и одиночным касанием сохранён; движение пальца переводит касание в панорамирование.

## Совместимость
- Не меняются координаты участков, игровые сервисы и формат сохранений.
- Не меняется изометрическая сетка 128×64.
- Масштаб камеры ограничен диапазоном 0.55–1.6.
- Навигация работает поверх существующего основного DistrictWorld.

## Проверка
Ожидается GitHub Actions импорт ресурсов и headless-запуск Godot. Это не заменяет ручную проверку жестов на реальном телефоне и мыши на ПК; Godot Editor локально не запускался.
