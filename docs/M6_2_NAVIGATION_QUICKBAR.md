# M6.2 — Навигация и быстрые инструменты

## Левая навигация
- Карта — возвращает в режим просмотра и закрывает активный режим редактирования дорог.
- Строительство — прокручивает контекстную панель к действиям строительства и подсказывает выбрать участок.
- Услуги — открывает действующую панель коммунальных служб.
- Статистика — открывает финансовую сводку района.
- Достижения — открывает действующую панель прогресса и достижений.
- Журнал — открывает журнал экономических операций.

## Нижняя панель
- Строительство, дороги, асфальт, фонари, службы, бизнес и финансы.
- Все действия вызывают существующие обработчики систем.
- Горизонтальная прокрутка позволяет пользоваться всеми кнопками на узких экранах.
- Правая контекстная панель заканчивается выше нижней панели быстрых инструментов.

## Ограничения и проверка
- Это функциональный проход UI, не финальная графическая полировка.
- Статически проверены привязки обработчиков, наличие всех пунктов и адаптивные ограничения.
- Godot runtime, GitHub Actions и Web Export не запускались; визуальное поведение следует подтвердить в опубликованной сборке.
