# M2.25 — Изометрические здания и строительство в основной игре

## Цель
Подключить изометрическую карту к основной игровой сцене, сохранив существующие игровые сервисы, ID участков и формат сохранений.

## Что сделано
- Основная сцена теперь создаёт изометрический `DistrictWorld` вместо прежней прямоугольной отрисовки.
- Сохранены шесть существующих ID участков и их названия; первый участок остаётся домом Бабы Зины.
- Состояния `home`, `empty`, `building` и `built` отображаются на ромбической карте.
- Для стройки перенесены визуальные этапы: разметка и материалы, фундамент, подъём стен, крыша, окна/двери, коммуникации и финальное благоустройство.
- Сохранены публичные методы, используемые `main.gd`: выбор участка, данные сохранения, ремонт дома Бабы Зины, обновление прогресса и завершение стройки.
- Жители снова отображаются у соответствующих домов в изометрическом пространстве.
- Добавлены панорамирование мышью/касанием и масштабирование колёсиком в основной карте.

## Совместимость и границы
- ID участков и структура данных сохранения не меняются.
- Экономика, GameTime, ResidentService, ConstructionService и MoveInService не переписываются.
- Старый прямоугольный renderer остаётся в репозитории как исходный исторический вариант, но больше не подключается основной сценой.
- Изометрический preview M2.24 остаётся отдельной сценой для визуальных сравнений.
- Навигация и выбор объектов будут дополнительно отполированы в M2.26.

## Проверка
GitHub Actions импортирует ресурсы Godot и запускает основную сцену в headless-режиме. Это не заменяет визуальную проверку на реальном окне/устройстве; отдельный локальный Godot Editor здесь не запускался.
