# M2.2 — Единое игровое время

## Принятое правило
- 5 реальных минут = 1 игровой час.
- 24 игровых часа = 2 реальных часа.
- Новый мир начинается в 08:00 первого игрового дня.
- Игровое время продолжает идти, пока игра закрыта.

## Реализация
- Добавлен автономный `GameTime` с масштабом 12 игровых секунд на 1 реальную секунду.
- Сервис выдаёт текущие день, час и минуту, а также сигналы изменения времени и игрового дня.
- Текущий день и время отображаются в верхней панели интерфейса.
- Состояние часов сохраняется в отдельном блоке `game_time`.
- При загрузке к сохранённому игровому времени добавляется офлайн-время в масштабе 5:1.
- Старые сохранения без блока `game_time` остаются совместимыми и начинают отсчёт с 08:00 первого дня, после чего учитывают офлайн-интервал, если он есть.

## Границы этапа
- Этот этап создаёт единый источник времени для будущих расписаний, смены освещения, бизнес-графиков, сезонов и погоды.
- Поведение жителей по расписанию, динамическое освещение и графики бизнеса ещё не подключены.
- Таймеры строительства остаются в реальном времени и не ускоряются/замедляются игровыми часами.
- Мультиплеерная синхронизация времени не реализуется; проект остаётся offline-first.
- Godot Editor/runtime не запускался локально. GitHub Actions headless validation — автоматическая проверка проекта, но не замена визуальному тестированию на устройстве.

## Проверки
GitHub Actions запускается автоматически для PR и после объединения в main.
