# M2.16 — Персональные разговоры между членами семьи

## Цель
Дать игроку возможность влиять на конкретные отношения внутри семьи, а не запускать общий разговор сразу со всеми доступными родственниками.

## Что добавлено
- Для каждого жителя в панели дома создаются действия разговора с каждым другим членом семьи.
- Разговор возможен, если оба участника находятся дома или на прогулке.
- Успешный разговор повышает отношения выбранной пары на 3 пункта (до 100), настроение и удовлетворённость обоих участников на 1.
- Для каждой направленной пары «инициатор → собеседник» действует отдельный cooldown 60 игровых минут.
- Cooldown хранится в индивидуальном состоянии инициатора и переживает сохранение/загрузку.
- В семейный журнал добавляется запись с именами обоих участников.
- Обновлены GDD и эта документация.

## Совместимость
- Существующая общая команда разговора и автономные разговоры сохраняются.
- Старые сохранения не требуют миграции: новое поле cooldown создаётся при первом использовании.

## Границы
- Это простое социальное действие без ветвящихся диалогов, озвучки или анимаций.
- Автономная социальная система пока остаётся семейной и не выбирает целевую пару по личным отношениям.
- Экономика не меняется.
- Godot Editor/runtime локально не запускался.
