# M2.32 — Подготовка изометрического мира к транспорту

## Цель
Подготовить совместимую с общей сортировкой глубины основу для будущего транспорта, не запуская симуляцию движения.

## Реализовано
- Добавлен RoadPathNetwork — лёгкий граф текущей дорожной сети стартового района.
- Дорожные клетки формируются из тех же координат, что и существующая крестообразная геометрия дорог.
- Поиск маршрута между дорожными клетками выполняется поиском в ширину и возвращает последовательность изометрических мировых точек.
- DistrictWorld предоставляет get_transport_route() для будущих транспортных систем.
- Добавлен интерфейс set_transport_entries() для передачи отображаемых транспортных объектов.
- Транспортные записи включаются в общую очередь глубины; положение по точке опоры и порядок сортировки детерминированы.
- Добавлен базовый компактный изометрический силуэт транспортного объекта, который появляется только при передаче соответствующей записи.

## Границы этапа
- Нет автоматического появления машин, трафика, парковки, светофоров или поведения водителей.
- Нет изменения дорог, сетки, участков, жителей, экономики, расписаний или формата сохранений.
- Маршруты строятся только по существующей крестообразной сети; подъезды от участков и расширяемые дороги будут отдельными задачами.
- Передаваемые транспортные записи являются визуальными данными, а не состоянием симуляции.

## Проверка
GitHub Actions проверит изменения PR. Godot Editor/runtime не запускался в этой среде; визуальная проверка сцены потребуется отдельно.
