# M4.2 — случайные события района

## Реализация

- Добавлен отдельный `DistrictEventService`; новое событие может появляться раз в 3–5 игровых суток.
- Добавлены пять типов событий: неисправный уличный фонарь, засор ливневки, переполненные контейнеры, гололёд и яма на дороге.
- Для каждого события доступны два решения: платное устранение проблемы и бесплатное откладывание с потерей репутации.
- Профильные работники коммунальной службы уменьшают стоимость подходящего ремонта на 25–35%.
- Платные решения проходят через `EconomyService` и попадают в журнал операций.
- Успешные решения меняют репутацию и дают опыт; первое решённое событие открывает достижение.
- Активное событие, дату следующего события, состояние генератора случайных чисел и историю последних 20 решений сохраняет `DistrictEventService`.
- Если игрок не решает событие, новые события не накладываются поверх активного.

## Ограничения прототипа

События пока представлены текстом и выбором решения; они не создают физические повреждения объектов и не запускают автономные задания работников. Следующие этапы могут связать события с визуальными состояниями карты, реальными задачами служб и сезонными условиями.

## Проверки

Ожидаются GitHub Actions: импорт проекта, headless-запуск и Web Export. Визуальное поведение окна события на iPhone требует отдельного подтверждения.
