# M5.3 — динамическая маршрутизация транспорта

## Что добавлено

- Дорожная сеть предоставляет список конечных клеток — сегментов с одним дорожным соседом.
- Демонстрационные автомобили выбирают маршруты между текущими концами связной сети через существующий BFS-маршрутизатор.
- На исходной крестообразной карте сохранены прежние направления движения: две встречные машины по горизонтали и две по вертикали.
- Когда игрок расширяет дорогу, старый конечный сегмент становится внутренним, а новый сегмент — конечным. После завершения текущего рейса машина пересчитывает маршрут по обновлённой сети.
- Пересчёт выполняется при цикле повторного появления машины, поэтому движущийся автомобиль не телепортируется посреди маршрута.
- Существующие скорость, встречные полосы, задержки появления, плавное движение, визуальная детализация и сортировка глубины сохранены.

## Границы этапа

Это развитие демонстрационного трафика, а не полноценная транспортная экономика. Автомобили пока не перевозят жителей, не имеют владельцев, расписаний, топлива или пробок. Эти системы требуют отдельных этапов.

## Проверки

Ожидаются Godot import/headless launch и Web export. Публикация подтверждается отдельным main workflow после merge. Визуальное поведение новых маршрутов следует дополнительно проверить в опубликованной игре на iPhone.
