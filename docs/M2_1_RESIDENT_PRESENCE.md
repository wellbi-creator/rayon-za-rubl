# M2.1 — Первое движение жителей

## Цель
Сделать заселение заметным на самой карте: после появления семьи жители должны визуально оживлять район, а не оставаться только числом в панели.

## Реализация
- ResidentService предоставляет безопасный список занятых домов и численность каждой семьи для визуального слоя.
- DistrictWorld получает актуальные данные при загрузке сохранения и после изменения заселения.
- Для каждого заселённого дома отображаются небольшие top-down персонажи по числу членов семьи.
- Персонажи непрерывно проходят простой демонстрационный маршрут от дома к общей прогулочной зоне и обратно.
- Маршрут учитывает верхний и нижний ряд участков; анимация работает через игровой delta time и не меняет сохранённые данные.
- Визуальные жители появляются только для действительно заселённых домов. Незаселённые участки не создают прохожих.

## Границы этапа
- Это первый визуальный слой присутствия жителей, а не полноценный NPC AI.
- Пока нет индивидуальных имён и внешности, расписаний, рабочих мест, потребностей, диалогов, столкновений и динамических реакций на погоду или время суток.
- Маршрут демонстрационный и не использует навигационную сетку; полноценные маршруты и обход препятствий будут отдельной задачей.
- Скорость и состав движения не влияют на настроение, удовлетворённость или экономику.
- Новые денежные операции не добавлены.

## Проверки
- GitHub Actions headless validation запускается для PR.
- Godot Editor/runtime и реальное отображение на устройствах локально не запускались; визуальную корректность нужно подтвердить в последующем игровом запуске.
