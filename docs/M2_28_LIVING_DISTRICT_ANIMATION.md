# M2.28 — Оживление изометрического района

## Цель
Сделать жителей визуально частью района, связав их прогулки с существующим расписанием ResidentService.

## Реализовано
- Жители с активностью walking перемещаются по маршрутам стартовой изометрической уличной сети.
- Маршрут строится на основе домашнего участка, вертикальной улицы и центрального перекрёстка.
- Участники одной семьи получают разные временные смещения, чтобы не двигаться синхронной колонной.
- Во время ходьбы анимируются шаги, руки и лёгкое движение корпуса.
- Дома жители остаются рядом со своим участком с ненавязчивой idle-анимацией.
- Персонажи не отображаются на улице во время сна, работы и учёбы.

## Архитектурные ограничения
- Источник активности — уже существующие данные ResidentService; расписания и симуляция жителей не дублируются.
- Не меняются ID участков, сетка, сохранения, экономика, строительство и формат данных.
- Транспорт, полноценная навигация с обходом препятствий и индивидуальные NPC-маршруты остаются отдельными будущими этапами.

## Проверка
Изменения проходят GitHub Actions. Локальный Godot Editor/runtime не запускался; скорость, читаемость маршрутов и визуальную сортировку нужно дополнительно оценить в запущенной игре на ПК и телефоне.
