# M3.4 — ежедневные коммунальные расходы домохозяйств

## Реализация

- Добавлен отдельный `DistrictUpkeepService`; расчёт не смешан с визуальным слоем района.
- С наступлением нового игрового дня начисляется 150 ₽ на каждого проживающего жителя.
- Игровые сутки используют существующий `GameTime`: 5 реальных минут равны одному игровому часу.
- Списание проводится только через `EconomyService.try_spend`, поэтому каждая фактическая оплата попадает в журнал транзакций.
- Если денег недостаточно, неоплаченная сумма сохраняется как задолженность. При следующих игровых сутках сервис пытается погасить её частично, в пределах доступного баланса.
- При загрузке учитываются пропущенные игровые дни; начисления за офлайн-период используют текущее количество жителей как приближение прототипа.
- Состояние последнего оплаченного/обработанного дня и задолженность сохраняются вместе с игрой.
- Для старых сохранений без данных M3.4 отсчёт начинается с текущего игрового дня: ретроактивные начисления не создаются.

## Ограничения прототипа

Это базовая экономическая петля, а не полноценная коммунальная инфраструктура. Отдельные службы, персонал, техника, зоны обслуживания, тарифы по типу дома и качество услуг остаются отдельными задачами. Ставка 150 ₽ на жителя за игровые сутки является стартовым балансным значением и должна проверяться в игре.

## Проверки

- Изменения проверяются GitHub Actions: импорт и headless-запуск Godot, Web Export.
- Визуальное отображение и поведение на iPhone требуют отдельной проверки в опубликованной игре.
