# M5.12 — эффективность коммунальных служб

## Цель
Сделать численность работников значимой для результата службы, а не только для фонда зарплаты.

## Правила
- Для каждого направления эффективность рассчитывается отдельно.
- Без работников эффективность равна 0%.
- Каждый из первых пяти работников повышает эффективность на 20 процентных пунктов.
- Пятый и последующие работники дают 100% эффективности; общий лимит штата остаётся 10 на направление.
- Скидка на решение районного события пропорциональна эффективности и не превышает максимальную скидку, заданную событием.
- Примеры: при максимальной скидке события 30% один работник даёт 6%, три — 18%, пять — 30%.
- Зарплаты, стоимость найма, сохранения и существующие события не меняются.

## Интерфейс
В окне «Коммунальные службы района» каждая строка показывает численность, текущую эффективность и дневную зарплату.

## Совместимость
Эффективность вычисляется из уже сохраняемого количества работников. Новые поля сохранения не нужны; старые сохранения работают без миграции.

## Границы этапа
Автоматические работы, назначение зон, техника и влияние качества на постоянное состояние района остаются следующими отдельными задачами.
