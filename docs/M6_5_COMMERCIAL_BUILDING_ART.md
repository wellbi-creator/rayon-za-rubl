# M6.5 — Отдельные здания магазинов и заведений

## Визуальные варианты
- Магазин у дома: витринные полки и товары, нейтральная тёплая отделка, вывеска «МАГАЗИН».
- Пекарня: хлеб в витрине, золотистый навес, вывеска «ПЕКАРНЯ».
- Кафе: отдельная палитра, две уличные посадочные зоны, вывеска «КАФЕ».

## Данные и состояния
- `BusinessService.get_business_visual_data()` дополнительно отдаёт `type`, `upgrade_level`, `leased`.
- `DistrictWorld` использует эти поля при отрисовке участка с бизнесом.
- Фактический график и активность по-прежнему определяют состояние открыто/закрыто.
- Уровень улучшения влияет только на декоративные элементы фасада; аренда получает небольшой визуальный маркер.
- Визуальные данные не дублируются в сохранении: они каждый раз выводятся из текущего состояния бизнеса.

## Совместимость
- Жилые дома без коммерческого заведения продолжают использовать `_draw_house()`.
- Экономика, спрос, расписания, аренда, покупка и сохранение бизнеса не меняются.
- Старые сохранения не требуют миграции.

## Проверки
- Статически проверяется наличие трёх типов фасада, чтение типа/улучшения/аренды, использование реального графика и передача данных через существующие вызовы `set_business_plots()`.
- Godot runtime, GitHub Actions и Web Export не запускались; необходима визуальная проверка в браузерной сборке.
