# M2.23 — Фундамент изометрического мира

## Цель

Закрепить изометрическую 2D-проекцию как единую пространственную основу будущей карты, не переписывая за один этап действующие системы жителей, строительства, времени, экономики и сохранений.

## Реализация

Добавлен `IsometricGrid` (`scripts/world/isometric_grid.gd`):

- единый настраиваемый размер ромбической ячейки, по умолчанию 128×64;
- преобразование координаты сетки в экранную позицию;
- обратное преобразование экранной позиции в ближайшую ячейку;
- проверка попадания локальной точки внутрь ромбической ячейки;
- базовый ключ глубины и стабильное правило порядка отрисовки для ячеек;
- визуальная высота передаётся отдельным смещением и не изменяет логическую координату земли.

Обновлены GDD, техническая архитектура, дизайн мира и дорожная карта. Изометрическая перспектива заменяет Top-Down как целевой стандарт проекта.

## Границы этапа

- Существующая сцена района пока остаётся прежним визуальным прототипом; этот PR не выдаёт её за уже преобразованную изометрию.
- Существующие прямоугольные участки, отрисовка зданий, дорог, жителей и машин не мигрируют в этом этапе.
- Не меняются идентификаторы участков, формат сохранений, экономика, таймеры, симуляция жителей и UI.
- Не добавляются новые арт-ассеты.
- Полный переход карты и интеракций планируется отдельными следующими этапами.

## Проверка

GitHub Actions выполняет автоматическую проверку проекта. Проверка запуска Godot Editor/runtime на реальном устройстве в рамках этого этапа не заявляется.
