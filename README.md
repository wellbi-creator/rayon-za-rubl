# Район за рубль

Многоплатформенная игра-симулятор развития и управления живым районом.

## Запуск прототипа

1. Установите Godot 4.x.
2. Скачайте или клонируйте репозиторий.
3. В Godot Project Manager выберите **Import**.
4. Укажите файл `project.godot` в корне проекта.
5. Запустите проект клавишей F6/F5 или кнопкой Run.

## Управление прототипом M1

- Левая кнопка мыши / касание: выбрать участок.
- Правая кнопка мыши: перемещать камеру.
- Колесо мыши: приблизить/отдалить.
- На мобильном: касание выбирает участок, свайп перемещает карту.

## Текущая версия

M1 foundation — первая техническая основа Godot 4.x: тестовая карта, камера, выбор участков, интерфейс и демонстрационная стройка обычного дома.

Данные и механики будут расширяться поэтапно. Время стройки обычного дома в прототипе — 10 минут; стоимость 100 000 ₽ является временной тестовой настройкой и подлежит балансировке.

См. `docs/GDD.md`, `docs/TECHNICAL_ARCHITECTURE.md` и `docs/ROADMAP.md`.
