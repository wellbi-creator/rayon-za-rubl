# Район за рубль

Многоплатформенная игра-симулятор развития и управления живым районом.

## Статус проекта

- Этап: M0 — фундамент проекта.
- Движок-кандидат: Godot 4.x (решение подлежит технической проверке).
- Камера: Top-Down.
- Ориентация: Landscape First.
- Целевые платформы: PC, Android, iPhone.
- Основной режим: одиночная игра; локальное сохранение на первом этапе, облачная синхронизация рассматривается для будущего.

## Концепция

Игрок приобретает заброшенный район за 1 ₽, получает стартовый капитал 1 000 000 ₽ и начинает восстановление с дома Бабы Зины. Постепенно он ремонтирует и строит дома, заселяет семьи, развивает инфраструктуру, бизнес, дороги и коммунальные службы, расширяет территорию.

## Принципы разработки

1. Живой, визуально привлекательный мир с первого игрового прототипа.
2. Модульная архитектура и данные отдельно от игровой логики.
3. Адаптация интерфейса для ПК и горизонтальных экранов телефонов.
4. Системы проектируются расширяемыми, но реализуются поэтапно.
5. Изменения в основную ветку принимаются после проверки и подтверждения владельцем проекта.
